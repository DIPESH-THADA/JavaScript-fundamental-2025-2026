# JavaScript Fundamentals Practice

> A set of small JavaScript practice exercises organised as standalone HTML and script files. The repository is intended to document incremental learning and experimentation.

## Overview

This repository is part of **Dipesh Thada’s development portfolio**. It is documented to make the project’s purpose, technology choices, and local setup clear for recruiters, collaborators, and learners.

## Technology

| Area | Implementation |
| --- | --- |
| Primary stack | JavaScript, HTML, CSS |
| Repository type | Web application / interface project |

## Getting started

No package installation is required for the current static implementation.

```bash
git clone https://github.com/DIPESH-THADA/JavaScript-fundamental-2025-2026.git
cd JavaScript-fundamental-2025-2026
```

Open `index.html` in a browser, or serve the repository through a local static server for a closer production-like experience.

## Repository layout
